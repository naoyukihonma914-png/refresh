# REFRESH（仮題）

旧題「UIアルケミスト」の作り直し。
PCブラウザ向けインクリメンタルゲーム。Created by PLATINA。

いまは**仕様づくりの段階**（Claude Code）。仕様が固まったら Codex が実装する。

## フォルダ
| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | Claude Code 向けの進め方と、次にやることの一覧 |
| `AGENTS.md` | Codex 向けの説明書（下書き） |
| `docs/企画メモ.md` | 経緯と決定事項（正本） |
| `docs/spec.md` | 仕様書（これから作る） |
| `docs/mockups/` | 画面の見本。`index.html` をブラウザで開く |
| `docs/handoff/` | ChatGPTからの引継ぎ資料、元ゲーム、最新試作（参考・編集しない） |

## 見本を見る
- パソコン：`docs/mockups/index.html` をダブルクリック
- リポジトリを公開（Public）にしている場合：GitHub Pages のURLから、スマホでも見られる
