# 海岸の壁紙

`coast.webp` は、このゲーム用に2026-10-31に新規生成した海岸風景。
既存のOS壁紙・写真・ロゴ・アイコンは使用していない。画像生成ツールで制作し、1920×1080のWebPに変換したもの。
ゲームのビルド時に単一HTMLへ同梱し、実行中に外部へ画像を取りに行かない。
256色の段階では描画時にRGB各6段階へ減色する。

`night.webp` は、このゲーム用に2026-11-01に新規生成した架空の港町の夜景。
既存の都市の名所やOS壁紙、ロゴ、標識は使用していない。画像生成ツールで制作し、
1672×941 のWebPへ圧縮したもの。日中と同じくHTMLへ同梱する。
