### 制作と配置の仮決め

- 制作先は論理640×416の実窓。共通の窓枠の矩形はクライアント領域で、タイトル帯はその外側。枠は内容を囲む容器として扱い、内容との重なりを禁止しない。他の兄弟パーツの重なりと窓外への配置は禁止する。ファイル・メール・写真は、それぞれ一覧／本文／画像と調整欄に適した配置を `balance.ts` に持つ。

- 要素は1つずつ実際の制作先DOMへ現れる。仕上げはそのボタン・入力・つまみ・一覧を操作する。大きく配置して一覧が全件収まった場合は、実項目の選択／読取フォーカスも仕上げとし、偽の行や汎用の確認ボタンは足さない。
- 完成後も配置を直せ、先に大きく作っても詰まらない。文字サイズに比例した保守的な最小寸法を共通化し、解像度の格子8／4／2／1へ切り上げる。表示用グリッドの間隔は、この配置用の格子とは別。文字を大きくする場合は、先に十分な面積へ広げる。

- 保存した既定の紫と、実際のOS標準材質を区別する省略可能なフラグを追加した。文字サイズ・角丸や記号色だけの変更で勝手にタイトル帯の配色を変えず、同じ紫を明示選択した場合はその通り表示する。記号色は帯の標準色を保ったまま個別に上書きでき、実窓・工房・静止撮影で同じ扱いとする。世界1／2の作業面は同じ関数で段別の標準背景を読み、明示色と［標準の色］を保存する。既存形式14でフラグがない場合は従来の色差による推定を維持する。

- **時計が戻った後**：不在の差を0として、その時点の端末時計を新しい不在の基準にする。以前の「時計が追いつくまで待つ」方式は廃止した。開いたままの時間には、端末時計の差で不在とみなす推測を入れず、単調時計の経過を使う。
- **書体の大きさ**：未収録の文字が欠けないよう全グリフを同梱したため、HTMLは約14.8MBになった。配布時の書体の絞り込みはまだ行っていない。組木やデスクトップの画面自体は作らず、仕様で指定された書体だけを準備した。
- **ブラウザの窓口**：全画面の切り替えは成功・失敗を返す。ブラウザの終了は実行せず失敗を返し、実績通知は何もしない。呼び出せない操作を飾りのボタンとして置いてはいない。
- **見本との差**：生成ボタン・作れるもの・世界の変化は引き続き段階2以降。通常画面は目標・所持数・保存状況の最小表示のまま。開発用小窓は、長い翻訳に合わせて幅を少し広げ、折り返しと最小24pxの操作領域を持たせた。

### 仮に決めたこと

| どこで | 何を | 仮の判断 |
|---|---|---|
| `state.ts`・`save.ts` | 保存形式と既存の試作 | 新しい形式を第1版とする。実在する旧版ができたら版ごとの変換を登録する。参考資料のセーブは推測で変換しない。未対応形式は元データを残して確認待ちにする |
| `save.ts` | 保存領域のキーと予備の扱い | `refresh.save` と `refresh.save.backup` を使用。保存時に正常な主データだけを予備に回す。壊れた主データで予備を上書きしない |
| `runtime.ts` | ブラウザの処理停止の判定 | 単調時計で5秒以上の停止、または端末時計で5秒以上経過し単調時計との差が1秒以上ある区間を不在として扱う。端末時計の差からストレージ上限まで計算し、直後に保存する。値は `balance.ts` の `inactivityGapMs` と `clockDriftToleranceMs` に置く |
| `time.ts` | 時計が過去に戻った後 | 不在の差が負なら0とし、その時点の端末時計を次の不在の基準に更新する。通常の能動時間は単調時計で測り、端末時計が元に戻るのを待たずに生成を続ける |
| `runtime.ts`・確認用画面 | ごく短い復帰の知らせ | 1秒未満または1ピクセル未満は通知を表示しない。計算自体には加算する。「0分・+0」の知らせを避け、1分未満は秒で表示する。世界ごとの最終的な通知は後の段階で実装する |
| 開発用小窓 | データの入出力と初期化の置き場所 | 各世界の設定画面ができるまでは `?debug=1` でのみ操作する。通常画面に仮の設定ボタンを加えない |
| `fixtures.ts` | 決まった状態への入口 | `foundation-start`、`foundation-saved`、`foundation-offline-capped` の3つ。実セーブを読まず、メモリだけに保存する。世界を飛ぶ操作は、その世界の実装時に追加する |
| `Foundation.tsx` | 土台を確認する画面 | 見本01の文書の体裁を使い、操作のない最小表示にする。生成・購入・動きは段階2で作る |

`game/` で `npm run dev` を実行し、表示されたURLに次を付ける。
