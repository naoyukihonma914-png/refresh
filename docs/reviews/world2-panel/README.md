# PR #29 パネル再構成の確認

`docs/世界2-パネル修正指示書.md` に従い、main の PR #30（`fae5541`）を `b9378fc` で取り込んでから修正。

## 変更

- 右パネルを1列の常設ゾーンへ変更。短期目標、共有／必須／任意の分類タブ、セット選択、パーツ選択、ピース一覧が同じ場所に残る。戻るボタンとチップ列によるドリルダウンを廃止。
- 初期分類は短期目標に従う。未購入セットのパーツも場所を確認でき、制作は購入後に有効になる。セットの選択と購入は別の操作にし、閲覧だけで資源を消費しない。
- 目標・分類タブ・ゾーン見出しを固定し、パネル本体だけを縦スクロール。「次はこれ」の印は全体で1個。
- 操作可能な面は浮き出し、状態は左端の色、選択は朱色 `#c8553d` の縁、無効操作は沈み込みと灰文字で区別。段②でも同じ区別を維持。
- 未装着の窪みは段①②とも不透明な灰色。装着するピースの配色と、ドラッグ時の吸着の強調は保持。
- メインパレットとスペクトルは作業台背景に適用。パーツ未選択でも使える。調整用の色と背景色を別の見本として表示し、部品の色は調整パネルから変更する。

制作・払い・完成・保存形式のロジックは変更していない。

## 見た目と操作の判断

セット行は、名前を押すと選択、価格を押すと購入する。購入できないセットでも内容を読めるよう、選択を無効にしない。未購入パーツは灰色で制作不可とし、購入だけで完成させない。

上部の高さを確保して短期目標の文面が変わってもタブとセットゾーンを動かさない。画面内に全件が入らないときは同じ列をスクロールし、必要な見出しを残す。

## 再確認の実行方法

`game/` で `npm test` と `npm run build`。リポジトリ直下で `python -m http.server 8183 --bind 127.0.0.1 --directory game/dist` を起動し、別の端末から `python tools/check_world2_panel.py --base-url http://127.0.0.1:8183/` を実行する。制作全体の確認は `python tools/check_world2_fitting.py --base-url http://127.0.0.1:8183/`。ハーネスは起動時に配信HTMLとローカルビルドのハッシュ一致を確認する。
