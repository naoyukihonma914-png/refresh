## 書体と資料の範囲

第1世代は13px/1.45、製品内容幅860px、写真480pxまで。指定のMS Pゴシック/MS UI Gothic/Osakaを優先し、代替OS書体としてIPAPGothicを指定する。確認用LinuxにはMS書体がないため、公式IPA Pゴシック003.03を`/tmp`へ一時配置し、FontconfigでMS系の名前も同書体へ解決した。ブラウザのCDPで本文・太字見出しがIPAPGothic、`isCustomFont=false`であることを確認した。第1世代24条件の太字見出しについても同じ検査を保存した。ゲーム画面の中に写したデスクトップは、撮影時の段・言語・元の描画部品を保つ。

[参考資料](screen-references.md)の公開マニュアル・現行詳細ページ・年代別の公式説明から構成を確認。指定年代のWayback保存ページは取得できず、認証後の作者ページ本体も未閲覧。当時の実画面の寸法や色を実測したとは扱わない。

## 自己確認

- 実在のロゴ・ブランド名・製品名・他社アイコンをゲームUIへ追加していない。
- 固有の配色/装飾・文言・画像を転用していない。朱色の差し色以外は一般的な白灰の表・罫線・ページ構成として組み直した。
- 他サービスの参考画像をリポジトリへ入れていない。今回差し替えた3枚は自作ゲームを操作して撮影した画像のみ。
- 仕様にない判断は[実装メモ](../../実装メモ.md)へ記録し、仕様書・企画メモは書き換えていない。

再現：ゲームをビルドして`/play/`で配信し、`python tools/check_stage7_screens.py --base-url http://127.0.0.1:4173`。MS系のOS書体がない環境ではOSの代替書体が使われる。今回のOS書体検証は`FONTCONFIG_FILE=/tmp/refresh-era-fontconfig.conf`を継承したChromiumで実施した。
