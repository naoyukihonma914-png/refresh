## 骨格の合格確認と画像

製品ページは、第1世代の狭い中央詳細→第2世代の左情報/右製品のポータル→第3世代の全幅ヒーロー/大メディア列。出荷は、第1世代の三列表→第2世代の大きな棒グラフ中心のポータル→第3世代の左ナビ/KPI/大推移/下明細。3列の比較画像を目視し、縮小しても骨格の差を判断できることを確認した。

報告用の成果物は`game/artifacts/stage7-layouts/`。`index.html`に操作・途中状態を含む186枚、`comparison-store.png`と`comparison-sales.png`に横並び、`reference-comparison.html`に変更前後の16枚、`stage7-layouts-screens.zip`にこれらと記録をまとめた。PRへ全セットは入れない。

PRの中心の完成形6枚は[一覧](README.md)を参照。第1世代の製品/出荷と試作版の補助画像は既存ファイルを変更せず、第2・第3世代の4枚だけ追加した。比較用ボードはPRへ追加していない。

ブラウザ結果の数値・書体・情報集合・比較差分は[screen-browser.json](screen-browser.json)。SSRの20件は可視の本文・レビュー・実額・7項目の性能・disabled・受託の選択肢まで検査し、値属性だけの一致には依存しない。作者なし、写真なし、試作版、集計中、性能の上限、資金不足、60Hz購入後も確認する。

## 書体・参照・自己確認

第1世代は13px/1.45、内容幅860px、OSのゴシック体。確認用Linuxでは公式IPA Pゴシック003.03を一時配置し、MS系の名前を同OS書体へ解決した。CDPで太字見出しもIPAPGothic、`isCustomFont=false`と確認。第2・第3世代は現代のサンセリフ。第3世代の角丸・影・広い余白は今回の明示指示に従う。

実在モデルは[参考資料](screen-references.md)の公開画像を画素で目視し、現行HTMLの確認と公開当時の画像を区別した。直接Chromiumでの外部サイト表示は環境証明書で失敗したため、通常の証明書検証で取得できる公開資料を使った。

- 実在のロゴ・ブランド名・他社アイコン・固有の配色/装飾・文言をゲームUIへ転用していない。
- 参考画像や取得した外部HTMLはリポジトリへ入れていない。今回追加する画像は自作ゲームの4枚のみ。
- 新しい数値や未実装の機能は追加せず、仮決めは[実装メモ](../../実装メモ.md)へ記録した。

## 再現

ゲームをビルドして`/play/`で配信し、`python tools/check_stage7_screens.py --base-url http://127.0.0.1:4173`。次に`--mode semantic --resume`で情報集合を確認、`--mode reference --reference-url <変更前ビルドの配信元> --resume`で前後比較、`--mode artifacts --resume`で比較ボードとZIPを再生成する。今回の変更前ビルドはa88f389から作り、4191で配信した。MS系の書体がない環境のOS代替書体は環境に依存する。
