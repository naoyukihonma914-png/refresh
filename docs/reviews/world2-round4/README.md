# PR #29 第4ラウンドの確認

`docs/世界2-修正指示書-第4ラウンド.md` を正として、既存ブランチ `codex/world2-fitting` に追加。文書PR #32のマージは待っていない。

## 変更

- ピースゾーン下部の調整ボタンを廃止。選択中のパーツ行だけに「カスタマイズ」を表示する。制作中・完成済みの両方で同じ調整パネルを開け、既存の閉じる操作で戻れる。段①②に対応。
- 第1周の初回エクスポートで通常の1トークンに加えて3トークンを進呈。榎本の `updateAvailable` の案内にアップデート資金として表示する。所持は4、アップデート購入後は1になる。一括書き出しでも進呈は1回。
- 進呈済みは永続の `tesseraUpdateGrantReceived` に保存。schema18の任意項目にし、旧セーブの欠落値を許容する。再書き出し・保存／再読込・案内の開き直し・次の版への移行でも二重に進呈しない。
- アップデートを購入するまで、エディタ・ページ設定・デスクトップのトークン購入を画面と処理の両方で閉じる。「先に Tessera をアップデートしてください」と理由を表示し、購入した瞬間に解除。無料の外観変更や通常のピース制作は引き続き使える。
- 案内を閉じても短期目標と消費制限は購入まで維持。第1周の旧セーブは通常の時間更新・工房の操作でも救済するため、書き出せるパーツが残っていなくても受け取れる。リリース画面で保存した第1周の旧セーブも通常の時間更新で救済する。長く止まっていたセーブでも、放置ヒントが資金の案内を上書きしない。

第1周は `run.version = v0.1` とする。第2周以降と、すでにアップデートを取得した旧セーブには遡及進呈しない。受取記録は周回をまたいで保持する。作品・書類・出荷済み製品の内容は変更しない。
