## 変更

- 独立したピース置き場を廃止。パーツを選ぶと、その全ピースが窪みと同じ寸法で作業台の下側に出現する。同じセットのパーツをトグル式で複数選択でき、全ての殻・窪みと、パーツごとに見出しを付けたピース一覧が同時に出る。各選択行にカスタマイズボタンを置く。
- ピースの行で個別に表示／非表示を切り替える。パーツを選択解除すると未装着ピースを隠し、はめたピースは残す。分類・セット・書類タブで行き先を切り替えると選択を解除する。
- 最初の出現位置は重ならない空き場所に割り当て、隠したりはめたりしても詰め直さない。隠したピース・装着済みピースの元位置も予約し、新しいピースは既存の元位置と仮置き位置を避ける。
- 窪みに吸着しなかったピースは落とした場所に仮置きし、その場から再ドラッグできる。装着済みから外した場合も同じ。右パネルや帯など作業台の表示領域外に落とした場合だけ、保存している元の出現位置へ戻す。仮置きでは払いも機能も発生しない。
- 段①②のパーツ行・ピース行を「既定は少し暗い／選択中は明るい／完了はチェック付きでさらに暗い」の3段階に変更。装着したピースと完成したパーツの選択は即時解除する。以前に完成したパーツから外した場合は、取得履歴を保持しつつ行の表示は現在の装着状態に従う。
- パーツ行には完成形のミニチュア、ピース行には窪みと同寸の実物を浮かべる。制作と同じレンダリングを使い、プレビューは操作や払いを発生させない。縦長プレビューは画面内に収める。実物のホバー・ドラッグ中は、大きさの合う空の窪みを薄く光らせる。

## 保存と判断

schema18の任意項目として、工房の `selectedParts`・`puzzleSet`、各パーツの `fitting.hidden`・`fitting.positions[piece].origin/at` を保存する。座標は作業台の基準寸法で持ち、ズーム・画面の拡縮・最大化は表示に反映する。保存の往復で選択・非表示・元位置・仮置き位置を保持する。

`spawned` と `paid` は既存の払い履歴として保持し、非表示を別項目にした。完成済みの取得・毎秒・日時・初回払いは取り外しても保持し、再装着で二重に払わない。任意項目のない旧セーブはそのまま受理し、ライブの制作画面を開いた時点で全ピース表示を初期化する。凍結した作品・書類・出荷済み製品を読み込み時に書き換えない。

パーツを改めて選択した場合は、隠していたものも含め未装着ピースを全て表示する。位置は保持する。出現位置を予約するため空きは残り、必要に応じて作業台をスクロールする。
