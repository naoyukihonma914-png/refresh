# PR #29 第6ラウンドの確認

この文書は第6ラウンド時点の記録。現在の制作・完成・保存は [グループパズル改修](../world2-group-puzzle/README.md) を参照。

`docs/世界2-修正指示書-第6ラウンド.md` を正として、既存ブランチ `codex/world2-fitting` に追加。文書PR #34のマージは待っていない。

## 変更

- 作業台のスクロールを廃止。窓・ピース・ドラッグ中の実物を同じ倍率で画面内に収める。完成予想と棚のための余白も確保し、どちらにもピースが隠れないようにした。窪みの基準寸法は変えず、選んだズームを上限として全体の表示倍率を収め、実際の倍率をステータスバーに表示する。
- 出現位置の割り当てを有限の基準範囲に制限。範囲内に行を増やし、非表示・装着済みの元位置も予約して詰め直さない。旧セーブの範囲外の元位置・仮置き位置は、読み込み時に範囲内の空きへ戻す。有効な座標と凍結した作品・書類・製品は保持する。
- ピースの文字を実際の文字幅・行の高さから縮小し、寸法を変えずに収める。入力値・翻訳・書体読み込み・表示サイズの変化にも追従。全セットの確認で見つかった、カレンダー下段のはみ出しも修正した。
- 吸着時に窪みの縁が短く光る。完成と同時に選択が外れても最後のエフェクトは表示し、キーボードのはめ込みにも対応。「動きを減らす」では描画しない。既存の吸着音は維持する。
- 上部のエクスポートボタンを記号と強い面色で強調。完成・未書き出しのパーツがある間だけ点滅して光り、全て書き出すと止まる。「動きを減らす」では光った静止表示にする。
- 元の形に囲む縁がないピースには、未装着・ドラッグ中・ピース行の実物プレビューにだけ細い縁を足す。既に縁のあるボタン・入力欄などには重ねず、装着後は外す。
- 書き出し時、実物の描画が縮みながらファイルのアイコンになり、作業台左下の「デスクトップ」棚へ飛ぶ。デスクトップ画面・ファイル・メールは、それぞれ全パーツの書き出しが揃うと1つのアプリアイコンにまとまり、短い合体アニメーションを出す。共通パーツなどは個別に残る。動きを減らす場合は演出を省き、結果を即時表示する。

## 保存・配置・演出の判断

- 棚は現在の周回の `parts[id].exportedAt` から復元する。別の払い履歴や永続フラグは増やさず、既存のセーブ対象をそのまま使う。旧セーブの書き出し済みパーツも棚に出て、新しい周回では空になる。トークン・記録・世界3の素材の実在は変更していない。
- 初期表示・再読込で過去の書き出し演出を再生しない。一括書き出しは各パーツを棚の行き先へ飛ばし、アプリが揃った場合は同じアイコンへ集めて合体する。表示中の実物がないパーツは上部ボタンを出発点にする。制作画面の実際の部品と機能は保持する。
- 基準範囲は1152×1600。画面には使用範囲の全体を等倍率で収める。元位置を予約したまま空きの行へ追加し、旧配置が細かく分断されて連続した空きが取れない場合のみ元位置を行へ整理する。範囲内の仮置き位置は保持する。
- 作業台のスクロールだけを廃止し、制作物自体のスクロールバーや一覧の操作は残す。制作のレイヤー表示を切り替えても、棚と画面への収納は維持する。
- 撮影では実操作でエフェクトを発生させた後、CSSアニメーションを途中の時刻で止めて絵を確認した。ゲームの状態や払いを注入していない。
