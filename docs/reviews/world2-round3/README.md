# PR #29 第3ラウンドの確認

`docs/世界2-修正指示書-第3ラウンド.md` に従い、既存ブランチ `codex/world2-fitting` に追加。PR #31のマージを待たず指示書を正として実装した。

## 変更

- 分類タブ・セット・パーツ・ピースの各ゾーン内で、選択以外を暗くする。朱色の選択枠を削除。非選択の操作面は浮き出したままで、無効操作は従来の沈み込みと灰文字を保つ。段①②に適用。
- 最小化・最大化・閉じるを、タイトル帯から独立した灰色の面と濃い記号に統一。装着後・置き場・ドラッグ中・新方式の素材を採用した実窓に反映。調整画面から個別のボタン色を除き、タイトル帯は引き続き調整可能。旧作品の配色データと凍結記録は維持。
- 置き場とドラッグ中に窪みと同じ幅・高さを使い、拡大・縮小用の固定寸法を廃止。大きなピースは置き場を拡張して収め、必要なら作業台をスクロール。キャンバス倍率・最大化・画面全体の拡縮を反映し、つかんだ位置も保持する。完成予想を畳んだ後は見出しだけの高さにし、空の面が下のピースを遮らないよう補正。

## 検証

- `npm test`: **74ファイル・759件成功**。`npm run build`: 成功、単一HTMLを生成。
- 全52パーツ・115ピースで、置き場とドラッグ中の幅・高さを実ブラウザの窪みと比較。小さい記号、薄い区切り、大きな面、縦長のスクロールバー、状態共有の座も対象。
- 段②の50%・100%・150%表示と窓の最大化時にも寸法一致。英語1280×720でも同じ測定とつかむ位置の保持を確認。
- 段①②の選択をゾーンごとに確認。窓ボタンは置き場・ドラッグ中・装着後とも `#c0c0c0` の面と `#101010` の記号。タイトル帯だけを変更した後もボタン色は一定。
- 従来の制作5ケース、日本語・英語のパネル12ケース（灰色の窪みを全52パーツ×2段×2言語で確認）、英語1280×720・動きを減らす設定の制作2ケースも成功。
- 制作・払い・完成・保存形式のロジックに変更なし。選択の朱色枠を前提にしたCSSとブラウザテストを除去。誘導・ヘルプの強調色は選択表示とは独立。
- ブラウザ例外・警告・外部通信なし。ビルドのハッシュと寸法の実測値は [summary.json](summary.json)。縮小画面の記録は [small-viewport.json](small-viewport.json)。
