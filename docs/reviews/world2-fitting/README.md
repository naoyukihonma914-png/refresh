## W2-1

- 全52パーツの殻、専用／共有／状態窪み、ピースの出現とドラッグ、任意調整、最後のピースによる完成を実装。
- schema18の旧制作途中の移行、旧作品の保持、再装着での重複払い防止、アプリに採用した記号順序を確認。
- 単体テスト721件成功、ビルド成功。1920×1080の実ブラウザで5ピースをドラッグし、逆付けした最小化、取り外しと再装着、同じ完成日時と財布、実スクロールを確認。ブラウザ例外なし。
- この段階では外側の旧シェルを使用。W2-2で見本02-1／02-2に合わせて置き換える。

## W2-2

- 段①②の外側を専用シェルへ置換。メニュー／書類タブ／設定帯、左パレット、右パーツ、ピース・コメント・カーソルのタイムライン、ステータスを実装。右端の道具列を撤去。
- パレットは色深度の固定色、前景・背景、スペクトルの選択、Idx表示。完成予想は同じピース描画を使った読取専用の小窓。
- 標準の表示倍率0.85／1.0とパーツ幅320／288。段②は暗色と細い段差に変わり、殻・ピース・調整のレイヤー表示を切り替え可能。段③は既存のGessoの見た目を維持。
- 40件の対象テストとビルド成功。1920×1080の5ブラウザケース（枠・段②・メール・入場・未完成の検索欄／スライダー）が成功し、例外と外部通信なし。最終の8画像はW2-3後のビルドで保存する。
- 見本との違い：行き先の窓は既存アプリと同じ論理640×416を保ち、見本の大きな例示窓より小さい。右パネルは指定の標準幅を使用。制作ノートは実際の内容をスクロールできる。

## W2-3 と最終検証

- パーツの初回完成時の段を記録し、基本の毎秒に段①×1、②×1.15、③×1.3を適用。採用済みアプリと保存した作品は、それぞれの記録を保持する。
- 段①のズームは50／85／100%のみ。段②以降は細かい刻みとフィット。初回エクスポートで榎本の案内と一度の短期目標を出す。
- 後続3技能（40／60／90トークン）は、対応世代が範囲外のため表示と購入可否の枠のみ。旧制作専用の効果がなくなった購入項目は外し、取得済み保存値は保持。
- `npm test`：73ファイル、749件成功。最終の表示修正後もキャンバス／実部品の10件成功。`npm run build`：成功。
- ブラウザ：1920×1080の5ケース成功。出現のみでは装着・報酬が発生しないこと、不適合窪み、記号の逆付けと実動作、再装着の財布・日時不変、部分的な入力欄とスライダー、メール列、レイヤー、OFF時の窪みを確認。
- 実アップデート：初回エクスポートの1トークンでは購入不可、3トークンを実際に貯めて購入。その後の進み具合のバーは `createdStage=1`、基本毎秒 `9×1.15=10.35` を確認。
- 補足：英語・1280×720・動きを減らす設定で窓枠の着脱と段②の実操作も成功。ブラウザ例外・警告・外部通信はなし。`file://` 直接起動の確認は実行環境のブラウザポリシーに遮断されたため未確認（HTTPでの単一HTML・同梱書体は確認済み）。

## 時間の診断（本調整なし）

`node tools/measure_world2_fitting.mjs` は実際の制作・支払い・エクスポート・アップデート処理で本線21パーツを進める。既存の人間操作の仮定を維持した計算で、人間による通しプレイの実測値ではない。

| 1パーツの制作時間の仮定 | v0.1 の表示要件の壁まで |
|---|---:|
| 90秒 | 43.7分 |
| 135秒（中間） | 59.4分 |
| 180秒 | 75.2分 |

中間は40〜60分の範囲内。遅い仮定は上限を超えるため、今後の人間によるテストプレイで確認が必要。細かい数値調整はしていない。計算の全記録は [economy.json](economy.json)。
