ここでは「決定／提案／未決定」を書き分ける。見本（HTML）は、その世界を詰めるときに作る（ユーザーの指示・2026-10-31）。

## 共通（決定済み・企画メモより）

- どの世界も簡素な姿から始まり、スキルツリーで最終的に最新の現代感の姿まで進化する（決定・2026-10-31）。各世界の案には「最初の姿 → 途中 → 最新の姿」の段を書く
- 入るためのスペック：4＝60Hz、5＝通信速度「高」、6＝描画性能「高」、7＝描画性能「最高」＋メモリ32GB

## 世界5 ウェブ

### 決まったこと（2026-10-31）
- 中心は**自分のサイトを組む**。ほかのサイトを巡るのは脇役
- ウェブは伸びしろの大きい題材なので、**見た目の変化と機能の充実を特に作りこむ**（ユーザーの方針）
- 育ち方の軸は**サイトの種類が変わっていく**こと
- 下の3つの柱と性能による見た目の変化を、方向として了承。細部はまだ案

### 決まったこと（2026-11-02 追加）
- 核ループ：**組む → 公開する → 訪問者の波が来る → 反応を見て直す**。「公開する」がこの世界の能動ボタン（世界3の「画面を撮る」に相当）
- 置ける部品は自分が作ってきたもの（描いたアイコン、スクリーンショット、配信の録画、文章の部品、商品棚など）。置く場所と順番、ページ同士のリンクのつなぎ方が、訪問者のたどり着き方に効く
- 訪問者は目的を持って動く（作品を見る、録画を見る、買う）。目的の部品が遠い・分かりにくいと途中で離脱する（カーソルが去るのが見える）。配置の判断がそのまま収入に効く
- 要望の受け口はコメント欄と問い合わせフォーム（世界3の要望メールの進化形）。応えるとトークン。トークンの出どころは紹介・レビューと合わせてここに一本化
- 見た目の段はサイトの種類の変化そのもの（自己紹介 → 作品集 → 日記 → お店 → 会員の集まる場所 → 道具として使えるサイト）。山場は「スマホ表示」（同じサイトが縦長に組み直される）と「動くサイト」（描画性能が足りないとカクつく。世界6への伏線）
- 架空のサイトは **5〜7個** に絞る。巡る目的は「部品とレイアウトの型を集める」こと（拾った型が自分の道具に増える）
- フィナーレ：自分のサイトに自分の製品のストアページを作って公開し、v3.0 をリリースする（発売形の決定・企画メモ「世界4・5の中身と発売形」）

### 入口と出口（提案）
- 入口：配信の録画が、自分のサイトのページに埋め込まれて始まる。画面いっぱいのブラウザ
- 出口：自分のサイトを録画した映像が、映像スタジオの素材になる（描画性能「高」が必要）

### 画面（提案）
- 画面いっぱいのブラウザ。白基調にせず、サイトごとにまったく違う見た目にする
- 主役の操作は2つ：①自分のサイトを組む（サイト作りの道具で部品を並べる）②リンクをたどる（脇役）
- 部品には、これまで作ったもの（描いたアイコン、スクリーンショット、配信の録画）をそのまま使う
- アクセス数の表やグラフを眺める「管理画面」にしない。主役は目に見えるサイトのデザイン

### 柱1 サイトそのものが育つ（方向は了承・細部は提案）
- サイトの種類が変わる：自己紹介の1ページ → 作品集 → 日記 → お店 → 会員の集まる場所 → 道具として使えるサイト。変わるたびにレイアウト・配色・遊び方が変わる
- ページが増え、サイトの地図が広がる。リンクでページを行き来できる
- 途中から「パソコン／スマホ」の表示の切り替え。同じサイトがスマホの縦長に組み直される
- 最後は動くサイト（スクロールで絵が動く、背景が映像）。描画性能が足りないとカクつき、映像の世界への壁にもなる

### 柱2 訪問者が目に見える（方向は了承・細部は提案）
- 訪問者を、素の画面のオートカーソルと同じ見た目の小さなカーソルで描く。スクロールし、ボタンを押し、お店で買う
- 数人のうちは1つずつ追える → 増えるとカーソルの群れ → さらに増えると光の粒の流れ
- ときどき起きる出来事：アクセス集中で重くなる、リンク切れ、スマホで表示崩れ。直すとお礼

### 柱3 ネットが広がる（方向は了承・細部は提案）
- 見た目のまったく違う架空のサイト（ニュース、通販、掲示板、百科事典、昔ながらの個人ホームページ、作品集など）を巡り、気に入ったデザインを集めて自分のサイトに取り入れる。リンクを張り合うと訪問者が流れてくる
- 検索の順位：本物らしい検索結果の画面の中で、自分のサイトが上がっていく（表ではなく画面で見せる）
- ストアのページ：自分の製品のストアのページを作れる。出来がリリースの売上に効く

### 資源（提案）
- ピクセル：自分のサイトの訪問者の数
- トークン：サイトが紹介されて話題になる、ストアに作品のレビューが付く

### 性能による見た目の変化（方向は了承）
- 通信速度：低いうちは画像が上から少しずつ読み込まれ、高いと一瞬で開く
- 描画性能：低いうちは動く背景がカクつき、上がると滑らか

### 未決定
- 解放の順番、値段、スキルツリーの項目（1周目帯／2周目帯／3周目以降帯）
- 架空のサイトの種類（数は5〜7個に決定）と、デザインを集める仕組みの細部
- 画面の見本

## 世界4 配信

詳細仕様の案を `docs/世界4の詳細仕様.md` に作成した（2026-11-03）。下の「未決定」への回答案と、部品表・段の定義・放送中の仕組みの細部はそちらに置く（承認後にこちらへ反映）。

### 決まったこと（2026-11-02）
- 核ループ：**場面を組む → 配信する → 放送中に場面を切り替えてコメントに応える → 録画が残る → 直す**
- 場面の素材は自分が作ってきたもの（デスクトップのキャプチャ、組木のキャンバス、作ったアプリの画面、スクリーンショット）。テロップ・枠などの演出部品も自分で作る
- 放送中の主な操作は場面切替。コメントの空気に合った場面に変えると視聴者が増え、同じ画面が続くと減っていく。コメントの要望に場面で応えるとトークン
- 自分の配信者アイコンをドットで描く（組木の腕前が効く）。顔出しの代わりに、描いたアイコンが画面の隅でコメントに反応する
- 放送が終わると録画と切り抜きが残り、閉じている間も再生で稼ぐ。録画は世界5のサイトに埋め込む映像になる
- 見た目の段（方向）：テスト配信（静止画＋コメント欄）→ 通常配信 → 演出つき → 番組構成（場面の複数持ち）→ 最新の配信スタジオ。滑らかさはリフレッシュレートが画面に出る
- 資源：ピクセル＝視聴（同時視聴×時間、反応）と録画の再生／トークン＝コメントの要望・称賛・常連の応援
- 視聴者の見せ方は流れるコメント（世界5の「ページを動くカーソル」と分ける）

### 未決定
- 解放の順番、値段、スキルツリーの項目、場面の数の上限（メモリに効かせる案）
- 出来事（おすすめに載る等）の細部、画面の見本
