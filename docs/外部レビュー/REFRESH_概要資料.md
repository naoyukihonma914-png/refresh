## 1. 一言で

**ボタン1つしかない真っ白な画面を、自分の手で「なんでも作れるパソコン」に育てて、製品として出荷していくゲーム。**

作っているのは、いま操作している画面そのものです。新しい部品を作ると、その場で画面が変わります。何度も出荷（リリース）するたびに性能が上がり、画面は90年代の古いパソコン風から、最新のパソコン風へと時代を進めながら進化していきます。

English pitch (draft): *An incremental game where you grow a blank page with a single button into a fully working computer — then ship it as a product. Everything you build changes the very screen you are using. Each release upgrades your hardware, and your desktop evolves through the eras, from a 90s-style gray desktop to a modern one.*

## 3. 遊びの流れ（最初の約8時間）

1. **導入**：自分が書いた計画のメモ「制作ノート.txt」が開く。「ボタン1つの画面から、自分のパソコンに育っていくソフトを作りたい」「画面はピクセルでできている」「いつかは、この画面ひとつで何でも作れるようにしたい」。［はじめる］を押す（画像01）
2. **素の画面（世界1）**：真っ白な画面に「ピクセルを1個生成する」のボタンが1つだけ（画像02）。押して集めたピクセルで、ボーダー → セーブ → オートカーソル（自動で押してくれるカーソル）→ カラー → フォント → レイアウト → アニメーションを作る。作るたびに、その場で画面が整っていく。数分間は誰も話しかけてこない（画像03）
3. **ガイドの登場**：色を作った直後、小さなソフトの販売元「余白社」の担当者・榎本から連絡が来る。「出来上がったら、うちで売らせてもらえませんか」。顔は描かず、文面だけ。口調は丁寧で短い
4. **Tessera（世界2）**：ドット絵の道具を作ると、さっきまでの画面は、道具の中で編集する書類「ホーム画面.ui」になる。アイコンを1ドットずつ描くとピクセル、描き上げて書き出すとトークン（2つ目のお金）が手に入る。作ったパーツ（ボタン・入力欄・窓の枠…）をホーム画面に置くと、本当に動く（画像04・05）
5. **最初の出荷（試作版 v0.1）**：「デスクトップとして組み立てる」には 256色が必要。でも今は16色しか出せず、先に進めない。そこで榎本が、いまの画面を試作版として出すことを提案する。製品に名前を付けて出荷すると、売上がドル（3つ目のお金）になる。ドルで「スペック」（色の数・解像度など）を上げると、作った画面は手放して、最初から作り直す（画像06）
6. **作り直し（v1）**：256色になったので、同じ素の画面もはっきり色が豊かに見える。今度は Tessera の先に進める
7. **デスクトップ（世界3）**：90年代半ばのパソコン風のデスクトップが立ち上がる（画像07）。アプリ（ファイル・メール・写真・時計・ターミナルなど）は、買って終わりではない。Tessera で**自分で部品を並べて組み立て**、デスクトップに入れる（画像08）。主な稼ぎ方は2つ。1つは「スクリーンショットを撮る」（写っている部品が多いほど稼げる）。もう1つは「フィードバック（利用者からの要望メール）に応える」（トークン）。オートカーソルを窓に割り当てると、そのアプリで働く
8. **v1.0 の出荷へ**（出荷の画面は未実装）：大型アップデートでデスクトップが2000年代前半風（画像09）、2000年代末のガラス風（画像10）へと時代が進む。ペイントソフトも Tessera から Gesso に乗り換わる。条件をそろえて v1.0 を出荷すると、次の版のテーマ（配信）が示される

## 4. 7つの世界（版が上がるごとに1つずつ増える）

使う人の輪が「自分 → 自分のパソコン → 視聴者 → ネットの人々 → 映像を見る人 → プレイヤー」と広がっていく。前の世界で作ったものは、次の世界の材料になる。

| # | 世界 | 画面の印象 | 新しく覚える操作 | 入るための性能 | 状態 |
|---|---|---|---|---|---|
| 1 | 素の画面 | 白・文字だけ → 整ったページ | 押す | ― | 実装済み |
| 2 | Tessera（ペイントソフト） | 暗い作業画面 | ドットを描く・パーツを作る | ― | 実装済み |
| 3 | デスクトップ | 写真の壁紙、明るい窓 | 窓を扱う・アプリを組む・カーソルに任せる | 256色 | 実装済み（段3〜5の時代は未） |
| 4 | 配信スタジオ | 暗い背景に鮮やかな映像 | 生放送中の場面の切り替え・コメントに反応 | 60Hz | 構想のみ |
| 5 | ウェブ | サイトごとに別世界 | 自分のサイトを組む（自己紹介 → 作品集 → 日記 → お店 → 会員の場 → 道具のサイト） | 通信速度「高」 | 方向だけ決定 |
| 6 | 映像スタジオ | 映画調、タイムライン | 時間軸で動きを付ける | 描画性能「高」 | 構想のみ |
| 7 | ゲームスタジオ | 3Dのビュー | 3Dの場面を組む・遊んで試す | 描画性能「最高」＋メモリ32GB | 構想のみ |

## 5. 中心の仕組み

- **3つのお金**
  - ピクセル：画面の中身を作る。量で、どんどん湧く。出荷するとなくなる
  - トークン：道具そのものの機能を増やす。書き出しや要望に応えるなど、やり遂げたときに入る。残る
  - ドル：出荷の売上。スペックに使う。残る
- **出荷＝転生**：作り上げた画面を製品として出荷すると、売上が「ピクセルの合計」と「作ったものの数（完成度）」で決まる。出荷した版はお客さんのものになるので、次の版は上げた性能で一から組み直す。「構成を引き継ぐ」を取ると、前回の構成がインストーラーのように順に組み上がる
- **スペック＝画面の性能そのもの**：色の数（16色 → 256色 → フルカラー → HDR）、解像度、リフレッシュレート、メモリ、ストレージ、通信速度、描画性能の7つ。上げると数字が伸びるだけでなく、**同じ画面が目に見えてきれいになる**。次の世界には性能の壁がある（「表示要件：60Hz以上（いまは30Hz）」）
- **スキルツリー**：世界ごとに、そのアプリの「プラグイン」「設定」の画面として入っている（外付けのメニューにしない）。1周目に取れるもの、2周目以降を前提にした重いものまで並べる
- **見た目の進化（いちばんの売り）**：どの世界も、古い・簡素な姿から最新の姿まで、配置・大きさ・色・素材がはっきり変わる段を重ねる
  - デスクトップ：95風 → XP風 → 7風 → 8風 → 10風 → 11風の6段。画面の大きさも時代に合わせる（800×600 → 1024×768 → 1366×768 → 1920×1080）
  - ペイントソフト：Aseprite 風の古い版 → 新しい版 → Affinity Photo 風の古い版 → 新しい版 → Procreate 風。名前も Tessera → Gesso → Brio と変わる
  - 素の画面：後の世界に進んで初めて、最初の画面の時代が変わる。90年代の素の HTML → 2000年代の個人ホームページ風 → 今の企業サイト風 → 今の誌面風
  - 実在のロゴ・OS名・アイコンの絵は使わない。作風・構図・質感だけを寄せる
- **自分で作る自由**：素の画面では、作るたびに決められることが増える。カラーで配色、フォントで書体、レイアウトで生成ボタンなどの位置と大きさ、アニメーションで動き。デスクトップのアプリも、部品の配置・色・大きさを自分で決めて組む
- **スクリーンショットと製品ページ**：撮った画面は進み具合のアルバムに残る。出荷のときは製品ページに載る。製品ページも版ごとに時代が進む（フリーソフト紹介サイト風 → ソフトウェア書庫風 → ゲームストア風 → アプリストア風。予定）
- **長く遊ばせる10の仕組み**（実装はこれから）：実績（1つごとに生成 +1%）、前の世界の成果が後の世界の倍率になる、手作業はいずれ必ず自動化できる、受託案件（しばりのある周回）、推定時間（何かを作ると「推定 60分 → 30分」と縮むのを見せる）、まとめ買い、タスクマネージャー（生成の内訳）、ときどき起きる出来事（取り残されたピクセル、Tessera のパーツのずれ直し、窓の「応答なし」）、隠し要素、その場で合成する効果音

## 6. 見た目とこだわり

- **本物のパソコンと見まちがえるリアルさ**。Windows のよく使うアプリ（エクスプローラー、メール、フォト、設定、ターミナル、タスクマネージャー）に忠実に寄せる
- **パソコンの画面の中で完結**する。モニターの枠・机・部屋は出さない。お金や購入も画面の中の部品として出す（ゲーム用の横の帯を置かない）
- **さわれない飾りを置かない**。1画面の主役の操作は1〜2個。未解放のものは「次の1つ」だけ見せる
- **AIが作ったっぽい見た目を避ける**（大きな角丸、ふんわりした影、カプセル形の札、鮮やかな青と紫、余白たっぷりのカード並べ）
- **懐かしさ**：30代の人が「この画面、知ってる」と感じる時代の再現を狙う（95・XP・7 の時代）

## 7. 時間の作り方

- 遊んでいる時間：押す、描く、撮る、要望に応える
- 放置：自動のカーソルやジョブが働き続ける
- 閉じている間も100%で進む。ただしストレージの性能（2〜24時間）が上限
- 1周の長さは約1 → 7 → 9 → 10 → 11 → 13時間と、ゆるやかに伸びる。数字は指数的に大きくなるが、待ち時間は少しずつしか伸ばさない
- 数値は全部仮。機能がそろってから、まとめて調整する

## 11. 変えない前提（企画者の決定）

- 最初から最後まで「UIを作る」ゲーム。作ったものが、いま操作している画面そのものを変える
- 画面の変化を楽しんでもらうことが最大の売り
- パソコンの画面の中で完結する
- 本物らしさを最優先にする。ただし、ロゴ・商標・既存の画像やアイコンそのものは使わない。Mac 風の三色ボタンも使わない
- 全編を白基調にしない。世界ごとに配色・構図・密度・文字・動きを変える
- 回路や3D空間の抽象的な世界には寄せない（前の試作で合わなかった）
