# デザインの決まり（見た目の手本）

作成：2026-10-30
見本（`docs/mockups/`）と実装の見た目は、この決まりに従う。仕様書 `docs/spec.md` の画面の色・書体の記述と食い違うときは、こちらを優先する。
方向の決定の経緯は `docs/企画メモ.md`「見た目の方向」。

---

## 1. 大元の方針
- **リアルさが最優先**。本物のアプリを横に並べても見劣りしない、細部まで忠実な画面にする
- 本物のアプリの**構図・寸法・色の考え方・操作の作法**は忠実に寄せてよい。ただし**複製はしない**：ロゴ、商標の名前、既存の画像やアイコンそのもの、独自の図柄は使わない。記号やアイコンは自作する
- **デスクトップは今のWindowsが基本**。アプリはWindowsでよく使われるもの（エクスプローラー、メール、フォト、設定、ターミナル、時計）を手本にする
- **組木は古いドット絵の道具（Aseprite のような）から始まり、現代の道具（Krita や Photoshop のような）へ進化**する
- 後の世界（配信・ウェブ・映像・ゲーム）も**現代のかっこいい見た目**。古い見た目にしない（古いのは素の画面と、最初の組木だけ）

## 2. 「AIが作ったような見た目」を避ける
| 避ける | 代わりに |
|---|---|
| 大きな角丸（12px以上）をどこにでも使う | 本物の寸法：窓8px、ボタン・入力欄4px、ドット絵の道具は0px |
| ふんわりした大きな影、色付きの光 | 窓だけに控えめな影。ほかは1pxの線で区切る |
| カプセル形の札・数字の入った丸いバッジ | 本物のアプリにある形だけ（タスクバーの未読数など） |
| 鮮やかな青（#3d7bff など）と紫の組み合わせ | Windowsの強調色（初期 #0067c0）。色は強調色1つと灰色の段階が基本 |
| 数字だけ等幅のプログラマー向け書体 | 本文と同じ書体で、桁をそろえる設定（tabular-nums） |
| 大きな数字を主役に置く、余白たっぷりのカード並べ | 本物の道具の密度：12px前後の文字、詰まった行、道具の帯、下の情報欄 |
| 項目ごとに説明文を1行付ける | 名前だけ。説明が要るものは、押したときやマウスを重ねたときに出す。ただし生成量が変わる買い物には、効き目を「×1.5」「+1」の形で短く添える（ユーザーの要望・2026-10-31） |
| 同じ太さの線だけの簡単な記号 | 1px単位で描いた小さな記号。アイコンは色の段階のあるドット絵（自分で描いたもの） |
| 色の点（●）を見出しの前に置く飾り | 置かない |

## 3. デスクトップ（Windowsが基本）
見本：`docs/mockups/03-desktop.html`

**書体**：`'Segoe UI Variable Text', 'Segoe UI', 'BIZ UDPGothic', sans-serif`（Windowsでは本物の書体、それ以外では BIZ UDPGothic で表示される）
- 本文・一覧：12px（Windowsの標準 9pt 相当）。見出し：14px 太字。窓のタイトル：12px
- 数字は本文と同じ書体＋桁そろえ

**色（ライト）**
| 用途 | 色 |
|---|---|
| 窓の地（タイトルの帯・道具の帯） | #f3f3f3 |
| 内容の地 | #ffffff |
| 区切り線 | #e5e5e5 |
| 文字 | #1a1a1a |
| 補助の文字 | #5f5f5f |
| 強調色（プレイヤーが組木で選んだ色。初期） | #0067c0 |
| 一覧の選択 | #cce4f7 |
| 左の一覧の選択 | #e6e6e6 ＋ 左に強調色の縦線 3px |
- ダーク（テーマアプリで切り替え）：窓 #202020、内容 #272727、線 #3a3a3a、文字 #ffffff、補助 #c5c5c5、強調 #4cc2ff

**窓**
- 角 8px、外枠 1px（rgba(0,0,0,.18)）、影 `0 8px 24px rgba(0,0,0,.28)`（前面の窓だけ少し強く）
- タイトルの帯 32px：左にアプリのアイコン 16px とタイトル 12px、右端に最小化・最大化・閉じる（各 46×32、1px の細い線の記号）。閉じるはマウスを重ねると赤（#c42b1c）
- 道具の帯（エクスプローラーの「並べ替え」など）は**手に入れた機能のボタンだけ**並べる

**部品**
- ボタン：高さ 32px、角 4px。標準は地 #fbfbfb、枠 #e1e1e1、下辺だけ #c8c8c8。強調は強調色の塗り・白い文字
- 入力欄：高さ 32px、角 4px、地 #ffffff、下辺に 1px の線（選ぶと強調色の 2px）
- スイッチ・スライダー：Windowsの形（スイッチは枠線の楕円の中に丸、スライダーは丸いつまみの中に強調色の点）
- 一覧の行：高さ 30〜32px、角 4px の選択

**タスクバー**
- 高さ 48px、地 #eeeeee の半透明（90%）＋背景のぼかし、上辺に 1px の線
- 作ったアプリのボタンを**中央**に並べる（各 44×40、角 4px）。開いている窓は下に灰色の短い線、前面の窓は強調色の長い線
- 右に、v1.0 までの進み具合・ピクセル・トークン・（時計を作った後）時計
- **左端のスタートボタンは置かない**（このゲームにスタートメニューの機能がないため。Windowsのロゴにも似せない）

**通知**：画面の右下（タスクバーの上）、幅 364px、角 8px。アプリのアイコンと名前、差出人（太字）、本文、下に横並びのボタン2つ

**画面を撮る**：画面の上中央の小さな道具の帯（Windowsの切り取りの道具の帯のような形）。強調色の「画面を撮る」ボタン、写っている部品の数、見込みのピクセル

**デスクトップのアイコン**：左上から縦に並ぶ。48px のアイコンと、白い文字＋黒い縁取りの影の名前（12px）。アイコンは組木で描いたドット絵

**資源の記号**：ピクセル＝黄色い2色のドットの小さな四角の組（8×8 のドット絵）、トークン＝緑のひし形（8×8 のドット絵）。紫や色の点は使わない

## 4. 組木
### 4.1 最初の組木（古いドット絵の道具）
見本：`docs/mockups/02-design-tool.html`（デスクトップの中の窓としては `03-desktop.html`）
- 書体：`'DotGothic16'`（ドットの日本語書体）12〜13px
- 立体の段差：明るい線（左上）と暗い線（右下）の 1px で浮き出す・へこむ
- 色：パネル #4a4950、作業台の背景 #3b3a40／市松模様 #2a292e・#302f35、くぼみ #232227、文字 #e9e4d8、補助 #d6d0c2、選んだ道具 #5b4a2a（明るい縁 #8a7444）
- 角は 0px。影なし
- 構図：上にメニュー（ファイル・編集・拡張機能）、左に道具の縦の列、その右にパレット、中央に作業台（キャンバス）、下に情報の帯（書類名・状態・倍率）

### 4.2 進化した組木（現代の道具）
見本：`docs/mockups/02b-design-tool-new.html`
- Krita や Photoshop のような、暗い灰色の作業画面。書体はデスクトップと同じ 12px、パネルは細い線で区切り、パネルの見出しは 12px
- 色の目安：地 #262626、パネル #2f2f2f、線 #3d3d3d、文字 #e6e6e6、補助 #a8a8a8、選択は強調色
- 進化のきっかけ（決定）：組木のスキルツリー2周目帯「道具を新調する」を取ると、古い道具の見た目から現代の道具の見た目に変わる

## 4.5 余白社（リリースの画面）
見本：`docs/mockups/04-release.html`
- 実際の販売管理の画面のように、表が中心。上に場所の帯（余白社 / 出荷 / 製品名）
- 色：地 #f4f1ec、面 #fffdf9、線 #ddd6ca・#ebe5da、文字 #24211d、補助 #6e665b、朱 #b8452f（強調は1か所だけ）
- 書体はデスクトップと同じ。角 4px、影なし

## 5. 素の画面
見本：`docs/mockups/01-seed.html`。スタイルのない素のHTML（白地・明朝体・素のボタン）。この決まりの例外で、作るごとに整っていく

## 5.5 他の言語
- 見本は日本語の手本。他の言語でも構図・密度・文字の大きさの考え方は同じ
- 書体は言語ごとに、同じ雰囲気の配布してよい書体を使う（仕様書 10.4）
- 英語・ドイツ語などで長くなっても崩れないよう、部品の幅は文字に合わせて伸びる作りにする。固定の幅に文字を詰め込まない

## 6. 見本を見せる前の確認
1. 1920×1080 で画像を撮り、文字のはみ出し・重なりがないか
2. 2章の「避ける」が1つも残っていないか
3. 押せない飾りがないか（帯やメニューに、まだ手に入れていない機能のボタンを並べていないか）
4. 本物のアプリの画面と並べて、寸法・文字の大きさ・行の詰まり方が近いか
5. ロゴ・商標・既存のアイコンを使っていないか
