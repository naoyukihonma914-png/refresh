# 世界2 改修指示書 — グループパズル化（2026-11-04・プラチナ決定）

対象ブランチ：`codex/world2-fitting`（PR #29）の上で継続する。Draft のまま、各コミット後に止まらず本指示の範囲を全部実装してから報告すること。
根拠：試遊フィードバック「ピースが細かくてめんどくさそう」を受けた方式変更。仕様の正は仕様PR #36（未マージ）だが、本書が自己完結するよう新方式の全文と対応表を以下に埋め込む。本書と現行 spec.md が食い違う箇所は**本書が優先**（PR #36 マージ後に spec が正になる）。

## 1. 方式の変更点（要点）

1. **購入単位＝グループ**。UIセットをやめる。必須ツールグループ＝ファイル＋メールを内包する1グループ。デスクトップ画面は独立グループ。任意ツール（写真・ごみ箱・時計・テーマ・ターミナル・タスクマネージャー・追加パーツ・配信）は従来のセット単位の購入のまま。
2. **共通パーツは作らない**。窓の枠・基本ボタン・見出しの帯・進み具合のバーは開始時点で作成済み。共通パーツセットの購入・制作フローは撤去する。4要素の毎秒レートは作成済みとして最初から各ツールのレートに含める。
3. **パズルの単位＝ツール**。グループを選ぶと、そのグループ内の未完成ツール全部のピースが混ざって作業台に出る。
4. **枠もピース**。殻の自動形成（行き先の窓に殻が出る方式）は廃止。枠ピースもキャンバスに出る。枠にはタイトルや刻印など行き先が分かる要素を入れ、ツールごとに区別できる見た目にする。置いた枠が組み立て場所になり、最初の要素ピースがはまるまでは移動でき、はまったら位置が固定される（はまったピースは枠基準の相対配置で追随）。デスクトップ画面グループは「デスクトップの地」ピースが土台役。
5. **完成＝アイコン化**。ツールの全ピースがはまると、演出（組みあがった姿が光って縮む）つきでツールアイコンに変化し、デスクトップ棚へ飛んで納まる。**トークンは完成時に、そのツールの旧パーツ数相当を一括付与**（対応表の「完成トークン」欄）。書き出しボタン・書き出し待ち状態・点滅・棚のアイコン合体は**すべて撤去**する。棚は残し、アイコンはツール単位で並ぶ。
6. **詰み防止の読み替え**：初回書き出し時→**サイクル1の初回完成時**に3トークン進呈し、Tessera アップデート購入まで他トークン購入をロック（既存実装の起点だけ差し替える）。

- 本編ピース総数 38。配信セットは今回触らない（現行のまま）。
- 要素ピースの毎秒レート＝統合した旧パーツのレート合算。ピース払い総額は従来の工程払い総額をピース数で割る（従来どおり）。
- 見出しの帯などの共通ピースは「出来合い」：ピース列に出るが細分化しない。状態ピース（未読／既読・実行／停止）は要素ピース内部の切替にし、ピース数を増やさない。
- 窓の枠の内部（タイトル帯・最小化／最大化／閉じる・スクロールバー）は一体化した完成形として描く（従来の共通パーツ完成状態の見た目を使う）。

## 3. 維持する基盤（第1〜6ラウンドの実装を壊さない）

- ドラッグ＆スナップ判定、窪みの発光（ホバー／ドラッグ時）、仮置き、嵌合エフェクト、作業台スクロール廃止＋全ピース画面内収容、ピース内文字の縮小、ドラッグ中も窪みと同寸、未装着窪みは灰色、窓ボタンは灰色固定、3段階の明暗表示、ホバープレビュー、デスクトップ棚、パレットの色＝キャンバス背景。
- 殻の代わりに枠ピースが土台になる点だけが変わる：要素ピースの窪みは**枠ピースの上**にあり、座標は枠基準の相対配置で保存する。

## 4. パネル構成の変更

- 分類タブは「必須ツール／デスクトップ／任意ツール」に変更（共有パーツタブは廃止）。
- ゾーン構成は維持：短期目標（最上部・常時）→ 分類タブ → グループ選択ゾーン → ツール選択ゾーン → ピース一覧ゾーン。
- グループを選ぶとそのグループの未完成ツール全部のピースが出る。ツール行の選択は「そのツールを目立たせる／短期目標の対象にする」意味に寄せ、ピースの出し入れの単位にはしない（ピース列はグループ内の全未完成ツール分をツール見出し付きで並べる）。
- カスタマイズの入り口は従来どおり選択中のツール行に出す。調整項目は従来の各パーツの項目を統合先の要素ピース／ツールへ付け替える（項目自体は変えない）。

## 5. セーブ形式

- スキーマを **19** に上げる。旧形式（18）の試遊セーブは移行せず、新規開始として読み替える（PR #29 は未リリースのため実害なし。移行コードは書かない）。
- 保存対象：購入したグループ、ツールごとのピース配置（枠の位置＋枠基準の相対配置）、はめ込み状態、棚のアイコン一覧、完成トークンの付与済み管理、進呈・ロック状態（既存）。

## 6. 画面文言

- 新規・変更文言は locales（ja/en）へ。既存の「セット」「書き出す」系の文言のうち新方式と矛盾するものは差し替える（画面の呼び方表：書き出す→エクスポートの対応は世界1の部品名など他箇所では維持。世界2の完成導線では「完成」系の文言を使う）。
- 短期目標・榎本の文言のうち、殻・書き出しに触れる箇所は新方式に合わせて差し替える。

## 7. スコープ外

- 共通パーツの「分解」の実装（将来仕様。データ構造で妨げないことだけ守る）。
- 配信セットの作り替え、数値の本調整（経済シミュレーションは従来どおり最後）。
- 世界1の作り替え、初回ガイド／ヘルプの実装（世界1再建側の範囲。ただし短期目標の文言差し替えは本書 §6 の範囲）。
