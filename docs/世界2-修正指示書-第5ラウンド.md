# PR #29 修正指示書・第5ラウンド（はめ込みのパズル方式）— Codex向け

対象：ブランチ `codex/world2-fitting`（PR #29）への追加コミット。仕様変更は文書PR #33 で main に入る予定ですが、作業はこの指示書の内容を正として進めてください。狙いは「1個ずつ出してはめる作業」から「ピースが広がっていて、合う同士をくっつけるジグソーパズル」への転換です。

## 1. ピース置き場の廃止と一斉出現
- キャンバス上の独立した「ピース置き場」の枠を廃止する
- パーツをパーツゾーンで選択すると、そのパーツの**ピース全てが選択状態になり、キャンバスの下側に一斉に出現**する。大きさは窪みと同寸（現行ルール維持）、ピース同士は重ならないよう配置する
- 出現位置は一度決めたら固定する。他のピースがはまった／消えた時に並びを詰め直さない。新しい出現は空き場所への追加のみ
- ピースの行（ピースゾーン）を押すと、そのピースの出現／消去を個別に切り替えられる。パーツの選択を外すと、そのパーツの未装着ピースは全てキャンバスから消える（はまったピースは残る）
- ピースのキャンバス上の位置（出現位置・仮置き位置）はセーブに残し、再読込で並びが変わらないこと

## 2. パーツの複数選択
- パーツゾーンのパーツ行は単一選択から**トグル式の複数選択**に変える。複数選択できるのは**同じセットの中だけ**（殻は行き先の窓1つに重なるため）。分類タブやセットを切り替えると選択は解除される
- 選択中のパーツ全ての殻と窪みが、行き先の窓に同時に表示される。ピースゾーンには選択中のパーツ全部のピースが、パーツごとの見出し付きで続く
- カスタマイズボタンは現行どおり選択中のパーツ行に出る（複数選択時は各行に出てよい）

## 3. 仮置き
- ドラッグしたピースが窪みに吸着しなかった場合、自動で出現位置に戻さず、**落とした場所にそのまま置かれる**（仮置き。はまっていないので払い・機能は発生しない）。仮置きのピースは再ドラッグできる
- キャンバスの外（右パネルや帯の上）で離した場合だけ、出現位置に戻る
- はめたピースをドラッグで外した場合も、落とした場所に仮置きされる

## 4. 明るさの3段階（パーツ行・ピース行）
現行の「選択以外を暗くする」を、次の3段階に置き換える（段①②とも）：
- 既定（未選択・未設置）：少し暗い
- 選択中：はっきり明るい
- 完了（パーツは完成、ピースは装着済み）：**チェックが付き、既定よりさらに暗い**
- ピースがはまった瞬間、そのピースの行は選択が外れて「完了」表示になる。パーツが完成した瞬間も同じ
- 分類タブとセット行は現行の暗転ルールのままでよい（3段階はパーツ行とピース行に適用）

## 5. ホバープレビュー
- パーツ行にカーソルを合わせると、そのパーツの**完成した姿**をプレビュー表示する（行の近くに浮かぶ小さい実物レンダリング。既存の完成予想ミニチュアの仕組みを流用してよい）
- ピース行にカーソルを合わせると、そのピースの**実物の見た目**を実寸でプレビュー表示する
- キャンバス上のピースにカーソルを合わせている／ドラッグしている間、**大きさの合う窪みが薄く光る**
