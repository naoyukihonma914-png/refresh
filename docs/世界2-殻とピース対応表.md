# 世界2 全パーツ「殻・ピース」対応表（決定・2026-11-03）

仕様書 §4.2「制作のしかた」の部品ごとの内訳。制作方式の改訂時はこの表を正とする。

現行カタログ（`game/src/content/workshopCatalog.ts`）の全セット・全パーツと、その要素リストを土台に、「殻＋ピースをはめる」方式へ読み替えた対応表。対象は仕様上の46パーツ（共通〜タスクマネージャー）に、追加パーツ（プラグイン2）と配信セット（4、世界4用）を加えた全52パーツ。

## 共通ルール

- **殻**：パーツを選ぶと、行き先の窓の中に実寸で現れる土台。殻自身がそのパーツの居場所と大きさを決める（旧・工程1「場所を決める」は廃止）。
- **ピース**：現行の「要素」がそのままピースになるのが原則。パネルでピース名を押すと作業台の端（右下のピース置き）に出現し、ドラッグして窪みへ。はめた瞬間にそのピースは実働する。全ピースがはまると完成。
- **窪み**：ピースの外形そのものの凹み。原則は専用の窪み1対1。ただし**同寸ピースは窪みを共有**し、どれにもはまる（機能はピースの記号・中身に従う）。共有する組は表で「共有」と明記。
- **例外的な統合**：窓の枠のスクロールバーは、現行の3要素（溝・つまみ・矢印）を1ピースに統合する（2026-11-03の一体化決定どおり）。
- **状態ピース**：未読／既読、実行／停止のように「2つの状態が1つの座を取り合う」ものは、2ピースを1つの座に重ねてはめ、切り替えで表に出る方が替わる形にする。
- **調整（こだわり）**：色・丸み・文字の大きさ等は、この表の対象外。現行のカスタマイズ項目をそのまま任意レイヤーへ移す。
- **工程払い**：旧工程払いの総額を、そのパーツのピース数で割ってピース単価とする（初回は均等割り。重み付けは数値調整時）。

## 数えた結果と気づき

- ピース数は1〜5個（大半は2〜3個）。現行の要素数とほぼ同じで、工程払いの総量は変えずに済む。
- 窪み共有（逆付けが面白い）になるのは今のところ2組だけ：窓の枠の最小化・最大化・閉じる／写真の前へ・次へ。他に同寸の組がほしければ部品側の設計で足せる（例：ファイルの並べ替えの順序ボタンを2つに分ける等）— 要検討。
- ピース1個のパーツ（基本ボタン）は「殻＋1ピース」の速いパーツとして残す案。物足りなければ、ボタンの「押し面」を殻から切り出して2ピース化する手もある — 要検討。
