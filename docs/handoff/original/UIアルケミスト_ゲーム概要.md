# UI・アルケミスト：ゲーム概要

PCブラウザ向けのインクリメンタル（放置・クリッカー）ゲームの試作版です。HTML1ファイルで動き、外部ライブラリは使っていません（フォントだけGoogle Fontsを読み込みます）。
Created by PLATINA

## コンセプト
ゲーム画面の部品そのもの（枠線・色・フォント・ウィンドウなど）を錬成して、プレイヤーが画面を自作していくゲーム。
重視しているのは「奥深さ」「斬新さ」「世界が広がっていく感覚」。
画面は 点（テキスト）→ 面（ウィンドウ）→ 線のネットワーク（回路）→ 立体（3D空間） と次元が上がっていく。

## 4つの時代（画面そのものが進化する）

### 1. テキスト期
- 素のHTMLのような白い画面に「[ ピクセルを1つ生成する ]」というリンク風のボタンが1つだけある
- 集めたピクセルで構成要素を錬成すると、画面の見た目がその場で変わる
  - 枠線 10px：ボタンに輪郭がつく。クリック+1
  - セーブ機能 30px：これを錬成するまでは保存されない
  - 色 80px：画面に配色がつく。カーソルの速さ×2
  - キーボード入力 120px：Spaceキーで押せる
  - フォント 250px：書体がつく。クリック×2
  - アニメーション 600px：これを錬成するまで画面は一切動かない。連打で「熱」が溜まる
  - デバッガ 1000px：画面にバグが湧く
  - ウィンドウ 2500px：次の時代へ
- 「カーソル」を買うと、ボタンの周りを回りながら自動で押してくれる

### 2. ウィンドウ期
- 6×4マスの「main.ui」ウィンドウの中にモジュールを置いていく
- 隣り合ったモジュールどうしが効果を及ぼし合う（コアの隣は×2、アンプの隣は+60%など）
- マスが有限なので、弱いモジュールを強いものに置き換えていくパズルになる
- 満杯になるとウィンドウ枠がガタガタ揺れだし、「フレーム破壊」（1000万px）が錬成できるようになる

### 3. 回路期
- ウィンドウ枠が砕け散り、無限に広がる回路の平面に出る。それまでの隣り合わせが配線に変わる
- ノードを選んで別のノードをクリックすると接続/切断。接続は1ノード4本まで（コア・ルーターは8本）
- コアにつながっていないノードは出力が25%に落ちる
- 「フィードバック」を錬成すると、閉じた輪（ループ）の上のノードに倍率がかかる（×2、「再帰」で×3）

### 4. 空間期
- 「Z軸」（300億px）で、真上から見ていた回路が傾いて3Dワイヤーフレーム空間になる
- ノードを上に押し出すと、高さ1段ごとに出力×2（「法線計算」で×3）
- 「レイヤー複製」で回路全体を上の階に重ね、全体の生産倍率を上げる
- 「次元の境界」（1垓px）を錬成するとエンディング

- 支援モジュール：アンプ（隣の出力+60%、重ねがけ可）、ミラー（隣の出力の30%を複製）、ルーター（効果を1段先まで中継）
- 同じモジュールを買うたびにコストは1.22倍
- 種類ごとの「改良」で出力×2、コア改良でクリック×2

## 中毒性を高める仕組み
- **シナジー**：各モジュールは一つ下の段のモジュールの所持数1つにつき+4%。ボタンはカーソル1個につき+1%。隣接・配線・ループの効果もあるので、古い部品が最後まで無駄にならない
- **段階的開示**：錬成できる要素はコストの一部に達すると1つずつ出現する。生産の内訳を見る「統計パネル」も自分で錬成する
- **アクティブとアイドルの両立**：放置中も100%で生産が続く（閉じている間も最大12時間分）。連打すると「熱」が上がって生産が最大10倍になる。時代ごとに見た目の違うバグを捕まえると、まとまった報酬か「オーバークロック」（12秒間 生産×7）がもらえる

## リファクタリング（転生）
- ウィンドウ期以降、その周回で100万px生成すると実行できる
- 得られる「圧縮コード」=（その周回の生成量 ÷ 100万）の立方根
- 累計コード1つにつき全生産+3%（コードを使っても減らない）
- 圧縮コードで「ライブラリ」を導入すると、次の周回が楽になる
  - 起動プリセット（1）：テキスト期の構成要素を最初から持つ
  - カーソル初期化（2）：カーソル20個で開始
  - 圧縮グリッド（3・8・20）：ウィンドウが横に1列ずつ広がる
  - ガベージコレクタ（4）：バグの出現頻度と報酬が2倍
  - ウィンドウ常駐（6）：ウィンドウ期から始まる
  - インライン展開（6）：時代を進める構成要素のコスト×0.2
  - 並列処理（10）：熱の最大倍率が×20になる
  - 自己記述スクリプト（10）：モジュールを自動で設置する
  - 永続ループ（15）：ウィンドウ期から2×2の正方形がループになる
  - 高次元キャッシュ（30）：転生後も改良レベルの半分を保持

## 演出
- 時代が変わるたびに画面が組み替わる（テキスト画面が縮んでウィンドウが開く／ウィンドウ枠が破片になって飛び散る／平面が傾いて3Dになる）
- 転生時は画面がコードの文字で埋まって「再コンパイル」される
- 効果音はWeb Audioで生成（連打の熱で音程が上がる）

## 調整の目安
自動プレイ（毎秒4クリック、その時点で最も効率のよい行動を選ぶ）での到達時間：
ウィンドウ期 2.5分 → 回路期 7.4分 → 空間期 29.5分 → エンディング 約60分
人が遊ぶとこの1.5〜2倍くらいを想定。

## 気になっている点（意見がほしいところ）
