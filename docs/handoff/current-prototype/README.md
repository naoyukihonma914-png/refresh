# UIアルケミスト 第4版

画面全体がゲーム内のPC環境になる試作です。物理的なディスプレイ、作業机、画面外のゲーム用サイドバーを廃止しました。元の添付ファイルと sources/ は変更していません。

## 進行

ピクセル → 生成アプリ → デザインアプリ → デスクトップ → 作業スペース → 環境マネージャー → ネットワークデスクトップ → 統合管理。

生成・購入・所持量は、生成アプリ、Canvasの部品インスペクター、デスクトップ内の部品ライブラリ、環境管理の操作欄に組み込んでいます。外側に別のゲーム用パネルは置いていません。

デザインアプリには写真を使った文書、レイヤー、ツール選択、写真の変更、ズームがあります。デスクトップにはファイル管理、編集できる制作ノート、タスクバー、最小化・復帰・最大化、ドラッグで移動できるウィンドウがあります。環境管理の表示から、内包している作業環境を開いて操作できます。

画面の基調は段階ごとに、無地、青灰色の生成ツール、文書編集、青緑の海岸デスクトップ、濃紺のスペース一覧、深緑系の仮想環境管理、夜景と暖色のデスクトップ、統合管理へ変化します。写真調のオリジナル壁紙2点を新規作成しました。左上の三色ボタンや既存OSのロゴは使っていません。

## 遊ぶ

Sitesの本人限定URL、または dist/index.html をブラウザで開きます。ローカルでは dist/ 全体を同じ場所に保存してください。インストールや外部通信は不要です。

最初はボタン一つ。ピクセルを集め、各画面内の「作成する」で27個の部品と拡張を購入します。カーソルは自動生成、生成リズムは手動と自動の配分、ゲージは20秒ごとの追加報酬を担います。描画・生成の操作は手動生成につながります。後半はカーソルの自動購入が利用できます。

旧版のセーブは維持します。自動保存、不在生産（最大8時間）、JSONでの書き出し・読み込みに対応。制作ノートの内容も保存します。元の添付ゲームのセーブとは互換性がありません。

## プレビュー

?preview=desktop などのプレビューURLで段階を比較できます。プレビューの生産は静止し、本編のセーブを書き換えません。右上の「表示」でプレビュー操作を隠せます。

昼と夜のデスクトップ、部品ライブラリ、環境管理を実際に操作できます。プレビュー内で行った変更は本編へ引き継ぎません。

## 確認

node check.cjs で購入条件、ゲージ、不正データ拒否、旧セーブ互換、全28購入状態の描画、描画サイズ上限、購入UIの内包、物理的な外部画面と三色ボタンがないこと、完成への到達、参照ファイルを検証します。

ブラウザでは初期画面、生成、購入、設定の開閉、保存後の復元、ウィンドウの最小化と復帰、ファイル閲覧、制作ノートの編集、内側の環境への移動、各後半画面の表示を確認しました。

毎秒2クリック、一定条件でカーソル購入、解放を優先する試算で完成まで693秒。実際の所要時間は購入判断で変わります。部品の自由配置・合成・転生は未実装。実際のOSやリモートPCへの接続は行いません。
