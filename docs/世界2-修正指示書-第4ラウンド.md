# PR #29 修正指示書・第4ラウンド（カスタマイズの入り口／アップデート資金）— Codex向け

対象：ブランチ `codex/world2-fitting`（PR #29）への追加コミット。仕様変更は文書PR #32 で main に入る予定ですが、作業はこの指示書の内容を正として進めてください。

## 1. カスタマイズの入り口（パネル）
- ピースゾーン下部の「調整を開く」ボタンを廃止する
- 代わりに、**パーツ選択ゾーンでパーツを選択した時、そのパーツの行にカスタマイズボタンが出る**（世界1のパーツごとのカスタマイズボタンと同じ考え方。未選択の行には出さない）
- カスタマイズボタンを押すと、そのパーツの調整パネルが開く（調整の中身・項目は現行のまま）。閉じる導線も現行のパネル側に合わせる
- 完成済み・制作中どちらのパーツでも、選択すればボタンが出ること

## 2. Tessera アップデートの詰み防止（方式B）
現状の数値：書き出し報酬は1パーツ1トークン（`BALANCE.workshop.exportTokens = 1`）、Tessera アップデートは3トークン。初回書き出し直後は1トークンしかなく、短期目標の「アップデートする」が買えない。

- **進呈**：初回書き出し（ゲーム全体で最初の書き出し。第2周目以降の周回では出さない）のタイミングで、通常の書き出し報酬とは別に**3トークンを進呈**する。榎本の案内（updateAvailable ガイド）の中で「アップデート資金」として渡す体裁にする
- **消費先の制限**：アップデート（editor skill `update`）を買うまでの間、**他のトークン消費先を閉じる**。対象はエディタのスキル購入など、この時点で到達できる全てのトークン消費（買えない理由が分かる表示にする。「アップデートが先」等の文言でよい）。アップデートを買った瞬間に制限を解除する
- 進呈は1回だけ。進呈を受けた事実はセーブに残し、再読込や再書き出しで二重に渡らないこと。第1周の既存セーブで「初回書き出し済み・アップデート未購入」の状態にも、次回書き出し時など自然なタイミングで進呈が届くよう配慮する（届かないセーブが残らないこと）
- 進呈後の所持は（書き出し分1＋進呈3）＝4トークン、アップデート購入で1トークン残る形でよい
