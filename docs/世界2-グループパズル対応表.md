# 世界2 全ツール「グループパズル」対応表（決定・2026-11-04）

仕様書 §4.2「制作のしかた」のツールごとの内訳。制作方式の改訂時はこの表を正とする。

2026-11-04 の方式改訂（グループ購入＋ツール単位のパズル＋枠ピース＋完成＝アイコン化）に基づく対応表。旧「殻・ピース対応表」（52パーツ・115ピース）は本表に置き換える。

## 共通ルール

- **単位**：パズルの単位はツール。グループを選ぶと、そのグループ内の未完成ツール全部のピースが混ざって作業台に出る。
- **枠ピース**：ツールごとに1枚。＝共通パーツ「窓の枠」そのもので、**タイトルや刻印など行き先が分かる要素**を入れてツールを区別できる見た目にする。置いた場所がそのツールの組み立て場所になり、最初の要素がはまるまで移動でき、はまったら固定される。デスクトップ画面だけは「デスクトップの地」が土台役。
- **要素ピース**：ツールごとに2〜4枚。従来のパーツは要素ピースへ統合し、毎秒レートは統合先に合算する。工程払い（ピース払い）は旧工程払いの総額をピース数で割る。
- **共通ピース（出来合い）**：見出しの帯・基本ボタン・進み具合のバーは作成済み。使うツールのピース列に出来合いの1ピースとして混ざる。細分化ピースは出てこない（分解は段③以降の将来仕様。細分化の定義は旧対応表の共通パーツ節を資料として残す）。
- **状態が対になる要素**（未読／既読、実行／停止）はピースを増やさず、要素ピースの中で切り替わる形にする。
- **トークン**：完成時に、そのツールの旧パーツ数相当を一括付与する（下表の「完成トークン」欄。仮値）。
- **調整（こだわり）**：色・丸み・文字の大きさ等はこの表の対象外。従来のカスタマイズ項目をそのまま任意レイヤーへ移す。
